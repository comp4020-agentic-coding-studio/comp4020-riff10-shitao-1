# Assets

Every picture and sound in Kiln is generated by code in this repository. There are no image, audio, model or font files, so there's nothing to license and nothing to download beyond the JavaScript.

| Asset | Where | Notes |
| --- | --- | --- |
| walls | `client/render.ts`, `plasterTexture()` | a 128×192 canvas: plaster speckle, block joints and a darker skirting, on one instanced mesh, alternating tints so corners read |
| floor | `client/render.ts`, `floorTexture()` | a 64×64 canvas of sandy speckle with a tile edge, repeated once per map cell so distance and speed are readable |
| crates | `client/render.ts`, `buildMap()` | plain boxes with dark edge lines; low and high heights from `shared/map.ts` |
| bomb sites, spawns | `client/render.ts`, `buildMap()` | translucent floor tints, and a big letter on each site drawn to a canvas texture |
| callout signs | `client/render.ts`, `textTexture()` | the place names from `MAP.callouts`, as sprites above each place, fading out up close |
| players | `client/render.ts`, `avatar()` | a cylinder body in the side's colour (T orange `#d9822b`, CT blue `#3d7fd1`), a sphere head and a box gun; crouching shortens the body |
| the gun in hand | `client/render.ts`, constructor | a receiver, barrel and grip, scaled per weapon slot, drawn over the world |
| tracers, muzzle flash, bullet marks, hit sparks, pings | `client/render.ts`, `fx()` | lines and small spheres that fade out |
| the bomb | `client/render.ts`, `buildBomb()` | a box with a light that blinks faster as the timer runs down |
| radar | `client/Game.tsx` | the map grid drawn to a 2D canvas each frame |
| interface | `app/globals.css` | system sans; dark translucent HUD panels |
| sounds | `client/audio.ts` | Web Audio: gunshots are filtered noise bursts plus a low tone, shaped per weapon and panned and attenuated by where they came from; hit ticks, hurt thuds, pings, the bomb's chimes and the explosion are oscillators and noise |

## Replacing them

- **A gun model**: replace `viewGunMesh` in the `Renderer` constructor with a loaded glTF (three.js's `GLTFLoader`), keeping it a child of `viewGun` so recoil and bob still apply, and set `depthTest = false` on its materials so it never clips into walls.
- **Player models**: `avatar()` builds one `THREE.Group` per player and `draw()` positions it, so a skinned model can replace the cylinder and sphere there. Keep the head at the height `shared/physics.ts` uses for hitboxes (`bodyTop(crouch) + 0.15`), or what players see stops matching what they can hit.
- **Wall and floor textures**: return a `THREE.Texture` from a loaded image instead of the canvas in `plasterTexture()` and `floorTexture()`.
- **Sounds**: `Sound` exposes `shot()`, `hit()`, `hurt()`, `beep()`, `explode()`, `click()` and `chime()`; replace their bodies with `AudioBufferSourceNode`s playing decoded files through `this.master` and the same `StereoPannerNode` placement to keep direction and volume.
